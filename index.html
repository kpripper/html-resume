Технічні навички

Backend

Розробка серверних застосунків на Node.js: проєктування backend-архітектури, побудова сервісів і скриптів для обробки даних, автоматизації та інтеграцій. Cтворення HTTP-сервісів, фонового виконання задач, обробки великих обсягів даних, оптимізації продуктивності та стабільності Node.js-застосунків у продакшені.

Express.js — побудова REST‑сервісів, middleware та API.

Бази даних

MongoDB — проєктування схем документів, робота з колекціями, індексами та агрегаціями, використання в Node.js‑застосунках для зберігання й обробки великих обсягів даних, оптимізація запитів.

PostgreSQL, MySQL — досвід використання реляційних баз даних у backend‑сервісах та скриптах: проєктування структури даних, робота з транзакціями, оптимізація запитів, імпорт і експорт даних.

API та інтеграції

Google APIs (YouTube, Google Cloud), Meta Graph API (Instagram, Threads), окремі Web API (Telegram, OpenAI, WordPress, PayPal, Cloudflare, HuggingFace, Openrouter).

Frontend

Розробка браузерних розширень для Chrome. Створення додатків - React, Vite, Astro, Next.js: SPA, SSR, SSG, взаємодія з backend‑API, збірка та оптимізація клієнтського коду.
